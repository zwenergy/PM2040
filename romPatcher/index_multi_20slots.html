GameKing slots (GK mini) need the 20 slot firmware with GameKing support. Tick "GameKing" for these slots (done automatically for files not ending in .min). A GameKing ROM larger than 512 KB continues into the following slot(s), which must then be left empty. Hold C while choosing a GameKing game to mute it.
**(Without the patch the GameKing blanks the screen after about two minutes without input and only wakes up after START is held for about two seconds. Only applied if the BIOS matches.)
*(Many commercial games will not shut the game completely off when pressing the power button, but will try to return to the same point when turning back on - which will crash when using the multi ROM FW. Thanks to zoranc for the patches.)
